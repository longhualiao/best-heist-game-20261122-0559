The Meridian Vault — an original top-down stealth heist game. Cross the museum floor, read the guards' patrols and vision cones, slip past the sweeping security cameras, lift the display cases and the gold, lockpick the Meridian Diamond, and run for the getaway doors before the alarm hits 100%. Sneak, crawl the vents, toss coins to pull guards away, smoke the cones, EMP the cameras. Every tool costs score, so every use is a trade.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD / arrows move, Shift sneaks, click tosses a coin, 1 coin, 2 smoke, 3 EMP, hold E to lockpick, R restarts.
